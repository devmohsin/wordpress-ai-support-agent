How it works

From docs URL to live chat widget in four steps.

1

Paste your docs URL

The agent crawls your documentation, help center, and FAQ pages — extracting and chunking all content into a searchable knowledge base.

2

Knowledge base is indexed

Every page is converted into vector embeddings stored locally. This is what lets the agent find the right answer for any question instantly.

3

Copy your embed code

You get a two-line script snippet. Paste it into any WordPress page, custom HTML, or your app's layout template.

4

Go live — agent handles the rest

Users see a chat bubble. They ask questions. The agent finds the answer from your docs and responds immediately. You only step in for escalations.
